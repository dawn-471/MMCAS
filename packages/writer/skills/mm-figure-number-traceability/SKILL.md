# 图表与数字溯源（论文手）

论文手是最后一道数字防线：正文、摘要、图表、结论里的同一个数字必须一致，且能回到运行记录。

## 登记表（建议放 `workspace/paper/`）

| 位置 | 数字/图 | 含义 | 来源 run_id / 文件 | 首次写入 | 最后核对 |
|---|---|---|---|---|---|
| 摘要 | 12.4% | 最优方案提升 | run-... / results.csv | ... | ... |
| 图 3 | ... | ... | ... | ... | ... |

- 位置写到摘要/章节/图号/表号；不要只写"正文"。
- 来源写 run_id（编程手台账）或数据文件 + 计算脚本；不能只写"队友给的"。
- 同一个数字在多处出现时，登记多行并指向同一来源。

## 交稿前核对流程

1. 从摘要开始，逐个数字查登记表；缺来源的标红，找编程手补 run_id。
2. 图表数字与正文数字对照；单位、精度、百分比/小数保持一致。
3. 结论中的"提升/下降/最优"必须能从表格或图中直接读出。
4. 任何数字变更：更新登记表、通知建模手、检查摘要/结论是否连带修改。

## 纪律

- 不凭记忆写数字；不从旧版草稿复制。
- 不用"约""左右"掩盖无法回溯的数字；要么补溯源，要么删掉。
- 图表标题/轴标签/图例写清口径（样本量、参数、单位）。
- 交稿前在任务卡标注"数字溯源已核对"；未核对不得提交。
